# Logotipos del informe

Coloca aquí los logotipos de las organizaciones (PNG o SVG, fondo transparente, unos 400 px de ancho)
y agrégalos en `src/config/acerca.json`, en la lista `logos`:

```json
"logos": [
  { "archivo": "logos/icc.png", "nombre": "ICC" }
]
```

Usa solo logotipos que tengas permiso de usar.
